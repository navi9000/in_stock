# О проекте

Скрипт для обработки файлов csv. Изначально предоставлены данные о наличии товаров на складе по состоянию на 30 апреля 2025 года в папке stock, а также данные по операциям за май, июнь и июль 2025 года в папке invent_trans. Задача: автоматически рассчитать наличие товаров на складе по состоянию на какой-либо день промежутка (напр., на 31 июля 2025 года).

# Запуск

py solution.py {YYYY-MM-DD}
